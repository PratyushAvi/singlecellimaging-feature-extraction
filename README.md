# Feature Extraction from Single Cell Images using CANVAS

This is a modified version of the [CANVAS](https://github.com/tanjimin/CANVAS) model that uses single cell images in place of tiles (WIP, not complete).

The jupyter notebook in the base directory is there for some basic analysis and data-processing. There are 3 shell scripts to run the CANVAS model on the NYU HPC. These need to be updated to work with the new Singularity system.
